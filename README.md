# Exercícios e Algoritmos — CS50x (Harvard University)

Este repositório contém as soluções dos desafios práticos (*Problem Sets*) desenvolvidos por mim até a **Semana 4** do **CS50x**, o curso introdutório de Ciência da Computação da Harvard University (via edX).

O objetivo deste projeto é registrar minha evolução prática em lógica estruturada, computação de baixo nível e resolução de problemas.

## 🛠️ Tecnologias e Conceitos Explorados (Até o momento)

* **Linguagem Principal:** C (com introdução conceitual a Python e SQL).
* **Fundamentos de Programação:** Sintaxe e tipos de dados, operadores, estruturas condicionais, laços de repetição (loops) e funções.
* **Algoritmos e Estruturas:** Manipulação de vetores (*arrays*), strings, técnicas de depuração (*debugging*) e análise de eficiência de código.
* **Algoritmos de Busca e Ordenação:** Implementação e conceitos de Busca Linear, Busca Binária, *Bubble Sort*, *Selection Sort* e *Merge Sort* (recursividade).
* **Ferramentas:** Git, GitHub e o ambiente Linux via CS50 Codespace.

## 📂 Estrutura do Repositório

As pastas estão organizadas de acordo com as semanas concluídas do curso, contendo os arquivos de código-fonte dos *Problem Sets* propostos pela grade de Harvard.
